# Windows Calculator 🧮
A Python-based Windows-style calculator application built using Tkinter, featuring a graphical user interface and basic arithmetic operations.

## Project Overview
Windows Calculator is a Python-based desktop application developed using Tkinter. It provides a graphical user interface that allows users to perform basic arithmetic calculations.

## Features
- User-friendly graphical interface.
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Interactive calculator buttons.
- Real-time calculation display.

## Technologies Used
- Python
- Tkinter

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python calculator.py
```

## Project Purpose
This project was developed to practice Python GUI development, event handling, and basic arithmetic operations using Tkinter.
